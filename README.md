# Mi App Prueba 1

Una landing page moderna creada con HTML, CSS y JavaScript.

## Cómo ejecutarla

1. Abre `index.html` en tu navegador.
2. O bien usa un servidor local como Live Server en VS Code.

## Archivos principales

- `index.html`: estructura de la página
- `styles.css`: diseño y responsividad
- `script.js`: interacciones del menú y formulario
